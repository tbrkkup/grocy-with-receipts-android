# Roadmap

## Planned Features

### Receipt Management
- [ ] Receipt list screen (browse, create, edit, delete receipts)
- [ ] Optional receipt picker in the purchase flow
- [ ] Customizable receipt display format in Android preferences (e.g. `{date} – {store}` vs. `{date} – {description}`)
- [ ] Link purchases to a receipt when booking stock

### Import Tool Integration
- [ ] `grocyimportv15` (external HTML tool) automatically creates and links a receipt entry on import
